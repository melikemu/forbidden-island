Forbidden Island
Ambient Experience System

A live companion system that connects board game states to environmental light and sound — transforming the room into an active layer of the game.

Role Lead Designer
Type Working Prototype
Integration Philips Hue + Web Audio API

Problem

Forbidden Island is a cooperative, role-playing board game with well-designed mechanics and defined tension curves. The game works. What works against it is the room. Static ambient lighting carries no information, no mood, no urgency — it signals that nothing is happening, regardless of what the board says. In a game where presence and group engagement are central, ordinary light quietly flattens player focus, reduces felt stakes, and pulls attention away from the shared experience.

Light is an underused variable in cooperative board game experience — and an unconsidered one shapes the room against the game.

Hypothesis

What if game states could be translated into environmental feedback instead of being tracked cognitively?

The goal was not to automate gameplay or replace the analog experience. It was to externalize invisible states — make them perceptible as shared, sensory events distributed across the room rather than silently held in players' heads.

System Design

This is not a UI project. It is a system that maps player actions to environmental outputs across three synchronized layers.

Multimodal Output
Physical The board, the players, the core cooperative gameplay
Digital A mobile interface that tracks state and dispatches triggers

The interface does not hold the experience. It orchestrates the room.

Interaction Model

The system is intentionally manual. Players trigger events themselves: a Waters Rise card drawn, a tile sunk, a treasure secured, a helicopter called. Nothing fires without a deliberate tap.

This decision preserves social awareness and group coordination. Manual triggering keeps the shared responsibility of the game intact — and turns each trigger into a ritualistic, collective act rather than a background automation.

Key Scenarios

Waters Rise
Escalating audio cue with a bass sweep. Room lighting shifts progressively deeper into the blue spectrum across ten mapped levels, from pale sky to near-black. Tension in the music layer increases proportionally.
Tile Sank
Four drama stages — Calm, Tense, Critical, Chaos — each with distinct audio texture and light behavior. Early stages: brief dimming. Later stages: sharp blinks with rumble tone, conveying structural collapse.
Treasure Collected
Each treasure maps to a distinct color (amber, red, green, cyan) and a unique ascending tone sequence. The room floods with color for two seconds, then returns to water-state baseline.
Helicopter Rescue
Rhythmic mechanical audio. Light strobes gold in a pattern suggesting departure, then settles.
Game Over / Victory
Game over: slow descending tones, room dims to deep red and holds. Victory: four-color sweep across the room, resolving to warm white.

Design Decisions

Decision Rationale
No automation Preserves social gameplay and shared responsibility. Automation would turn ritual into background noise.
Single shared interface Avoids fragmenting attention across individual screens. One trigger point keeps coordination visible to the group.
Soft transitions over abrupt changes Gradual light and audio shifts maintain immersion. Hard cuts would break the perceptual flow of tension-building.
Ambient lighting, not on-screen alerts Shifts focus from device to physical environment. The room becomes expressive; the phone recedes.
Procedural audio synthesis Each sound is generated in real time (Web Audio API), not sampled. Allows dynamic parameterization by game state.

Positioning

This project sits at the intersection of interaction design, ambient computing, and IoT-driven experience. It demonstrates how digital systems can extend beyond screens and into shared physical environments — making invisible states perceptible and silent moments felt.

Rather than replacing the analog experience, the system augments it. Design here is not interface creation. It is the orchestration of interaction across people, devices, and space.
